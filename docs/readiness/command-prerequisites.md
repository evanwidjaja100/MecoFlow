# Command prerequisite matrix

Required checks fail closed. A missing executable, service, environment file,
secret file, test file, generated contract, or isolated database is a failed or
blocked run, never a pass. Every evidence row also records source SHA, worktree
state, image digests where applicable, environment, start/end time, exit code,
test count, and output location.

Remote CI additionally emits a secret-free manifest bound to the source SHA,
lockfile digest, container-policy digest, runner, run attempt, aggregate job
status, every command argv/start/end/duration/effective exit, output hashes, and
zero-skip/zero-todo evaluation. Secret-redacted command logs, the always-run
manifest, and generated Playwright/test or complete container-scan output are
retained for 90 days as an immutable v4 artifact; its artifact ID/digest and
run-log URI must be copied into the evidence index before review.

## Uncached execution rule

For Turborepo-backed source gates, release evidence sets `TURBO_FORCE=true`
while invoking the exact repository command. Cache output may be diagnostic but
is never the only Phase 0 evidence.
