# QA/QC quick reference

1. Open the inspection work queue and confirm project, lot, item, quantity, and
   immutable check snapshot.
2. Record every required checklist/measurement/certificate result. A certificate
   is acceptable only when linked to the same inspection/project and its current
   version is clean and approved.
3. Select the disposition and exact accepted/rejected quantities. Any remainder
   is quarantined. Conditional acceptance requires its separate authority and a
   specific reason.
4. Finalize once; verify lot buckets sum exactly to the effective received quantity.
5. For nonconformance, create and issue the NCR to the exact supplier. Keep
   internal notes private unless explicitly approved for sharing. Review retained
   supplier responses before close.

Never allocate quarantined/rejected material or bypass failed certificate/scanner
checks. Treat quantity divergence, cross-project evidence, or missing audit as a
critical incident.
