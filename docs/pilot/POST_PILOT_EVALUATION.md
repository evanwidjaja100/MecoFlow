# Post-pilot evaluation template

Pilot dates: ____ Candidate/version: ____ Scope/projects/suppliers: ____

## Outcome

Decision: END / EXTEND WITH CONDITIONS / PREPARE NEXT RELEASE / ROLLBACK

Summarize objectives achieved, excluded scope, adoption, operational continuity,
acceptance results, restore evidence, security/isolation evidence, and decision owners.

## Evidence review

- KPI baseline versus final: attach completed worksheet and explain variance.
- Workflow volume/outcomes: BOM, requisition, PO, commitment, ASN, partial receipt,
  document, inspection, quarantine/NCR, allocation, readiness, report/export.
- Incidents/defects: severity, impact, containment, root cause, corrective action,
  residual risk, and whether workaround became process debt.
- User feedback by internal, supplier, warehouse, QA/QC, admin, and support role.
- Data quality/integrity: corrections, duplicates, reconciliation, audit completeness.
- Operational results: availability, recovery duration, support load, rollback readiness.

## Follow-up

For each action record owner, due date, acceptance evidence, priority, dependency,
and release gate. Do not convert requested features into commitments without a
separately approved scope. Record final sign-off and evidence-retention location.
